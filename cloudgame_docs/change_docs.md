# Add Cloudgame Service Information To ComputerDetails [(Click To See Commit)](https://github.com/MobinYengejehi/Artemis/commit/b2649c13b18556d254c642d0f64079d66513955b)

- Add `.CloudgamePort`
- Add `.HasCloudgameService`

# Add Cloudgame Service Client Token To ComputerDetails [(Click To See Commit)](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426)
At this commit we did a lot of work. But unfortunately we commited all of them at the same time by mistake.

1. At first we added the [`CloudgameService`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-07b6ec4920299b2744e9f476a9c019ec0939d362a39a884310d987db7bd465bfR33) class which creates an object that can communicate with `Cloudgame Stream Server`. It has bunch of methods which can execute commands like `Creating an stream session` or `Quiting from an stream session` and so on.
2. Then we added [`.cloudgameJWTToken`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-2e33c332e78f277a11d84d080dc05ea047581c1e447d61735fad8e7d54ce56b9R90) property to `ComputerDetails` class to be able to store the `Cloudgame JWToken` and use it in other activities.
3. After that we changed the way the application got [`Application Assets`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-9b5891a918deb637273430513bf0605ebf3b52dbcb87206af2d6e60f42b29fc4R26) from server like images and ... for the computers which support `Cloudgame Service`.
4. Then we changed the way the application checked if the computer is [`Online`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-87216e9e3153cfd5fb82833c8edf3d553224ed0b7f729704f5e651bad18d1965R570) or not for that computers which support `Cloudgame Service` and after that we used `CloudgameService` to get [`applist`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-87216e9e3153cfd5fb82833c8edf3d553224ed0b7f729704f5e651bad18d1965R899) from servers which support `Cloudgame`.
5. Then we added a new constructor to [`AndroidCryptoProvider`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-fdbdb112e49b7b082f92537f18957531f8d1fe3cc26c90540a63d4f957d6d949R58) to be able to pass `null` value for the `.certFile` and `.keyFile` properties. Then we defined a new method called [`getDummyProvider`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-94b4ed85dc510649f605ccfa0a8138291028d7668079b085279a965c6515f38bR15) on `PlatformBinding` class to bypass the `HTTPS` certification key files.
6. On `PcView` activity we created a new method called [`doCloudgameAuthenticationDialog`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-da32aa9be8b8620542d854dec77990e53085e8e833f220d4cbd3265ec8ba1b09R708) which opens a dialog with text input to use pass the `Cloudgame JWToken` instead of [`PIN Pair`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-da32aa9be8b8620542d854dec77990e53085e8e833f220d4cbd3265ec8ba1b09R452) authentication system for computers which support `Cloudgame Service`.
7. After that on `AppView` activity we changed the way client checked if the server is [`Paired`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-270de10884ab9167727db9d236ce8261cdf8bfc343ffb5ac910c473f418e3c01R249) or not for computers that support `Cloudgame Service`.
8. And then on `Game` activity passed the `Cloudgame Service` informations to be able to use [`CloudgameService`](https://github.com/MobinYengejehi/Artemis/commit/45638564d10aba0366087f424aeb7fba82d21426#diff-037e78586dc6a4cb90a396a1ce10a29d28d96912e7ee8f9f6b160dbf217bfe7eR473) on that activity too.
